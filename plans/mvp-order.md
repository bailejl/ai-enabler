## Rules that apply to every item

- A change that adds a save-file field adds its command, MCP tool and `llms.txt` entry (AC23 parity), plus its fixture, upgrade hop, JSON Schema file and plugin rebuild. Skills declare the schema major they support.
- A change that adds a failure mode adds its catalog code, repair guide and docs. After D2, a test fails on any catalog code with no guide.
- Durations are integer minutes of working time, converted only through the one units module (8 h a day, 5 days a week, 4 weeks a month). See Decisions.
- Schema-bumping rows merge strictly in table order. After E13 PR3, PRs that touch `src/flow` or `mcp/` merge one at a time, because the plugin bundle is committed.
- A new route or countable feature adds its route template or usage event (after N14, row 11).
- A new warning adds a `MAP_` check and reads the thresholds table (after rows 15 and 16).
- Each item adds or updates its help page (after N17's help frame, row 10).
- E12, N12 and skills that write the save file go through the validator and commands and set `modifiedBy`.

## Decisions

Approved by the user on 2026-11-22.

1. **Time unit.** Durations are stored as integer minutes of working time: 1h = 60, 1d = 8h = 480, 1w = 5d = 2400, 1mo = 4w = 9600. This blocks E13 PR3, whose `llms.txt` pins it. The worked example's hours convert ×60 on import.
2. **Duration display.** The UI shows the largest unit that fits whole, as a compact label: 5m, 2h, 4d, 3w, 4mo. Minutes are the lowest unit; the worst case is a few months.
3. **Reserve slots in E3a.** E3a's breaking bump reserves the metric slots (low, high, source, confidence), `edges[].type`, the box unit and trigger, and (added in v3) `batchSize`, `edges[].rate`, `edges[].ratio`, `maps[].endMarkers`, `maps[].name` and `maps[].basedOn`. N16, N8, E6, N4, N7, N15 and E7 add no breaking bump, and only rows 15, 18 and 24 bump after E3a (to 1.1.0, 1.2.0 and 1.3.0).
4. **E1 storage.** IndexedDB. Store the save-file text, and keep `modifiedAt` in the index, not in the file.
5. **Thresholds conflict.** The product plan's table wins and the metric tiles migrate to it (row 15). "Total queue" stays provisional at 20/50.
6. **Total lead time.** The critical path, not a sum over all steps, from E3b on. This replaces the ui-shell S7 decision that metrics sum over all steps.
7. **App version.** No separate item. D1 reads the version from `package.json` and creates `CHANGELOG.md`.
8. **Plugin home.** The plugin stays in this repo, and the bundle stays committed, under the serial-merge rule.
9. **Dependency cards.** Each remaining item gets a short card in `plans/mvp-cards.md` now; the full `/dev-team:specs` waits until the item starts. Every row from 8 to 27 has a card.
10. **Card defaults.** Every default in the rows 15–27 cards is accepted and marked "Accepted 2026-11-22" there.
11. **Order fixes.** Rows 20 and 21 need row 16 (they add map-health checks), and row 25 needs row 24 (the sample carries an outcome).
