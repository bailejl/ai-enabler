# APP_RENDER_FAILED: The app failed while drawing the screen

## What it means

The AI Enabler web app hit an error while drawing the screen and showed its fallback page instead of the map. This happens in the browser, not in the MCP server, and the project file is not changed by it.

## Repair with the tools

No tool repairs this.

Tell the user to reload the page to start again, and that changes made in the app since the last export are lost.

Tell the user that if it keeps happening, they can report the code APP_RENDER_FAILED.

## Ask the user first

None.
