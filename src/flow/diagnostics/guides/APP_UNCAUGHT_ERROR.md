# APP_UNCAUGHT_ERROR: An uncaught error occurred

## What it means

The AI Enabler web app hit an error that nothing in the app handled. This happens in the browser, not in the MCP server, and the project file is not changed by it.

## Repair with the tools

No tool repairs this.

Tell the user to reload the page if the app stops responding.

Tell the user that if it keeps happening, they can report the code APP_UNCAUGHT_ERROR.

## Ask the user first

None.
