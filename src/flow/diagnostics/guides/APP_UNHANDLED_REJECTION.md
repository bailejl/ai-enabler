# APP_UNHANDLED_REJECTION: A promise was rejected and not handled

## What it means

An asynchronous operation in the AI Enabler web app failed and nothing caught the failure. This happens in the browser, not in the MCP server, and the project file is not changed by it.

## Repair with the tools

No tool repairs this.

Tell the user to reload the page if the app stops responding.

Tell the user that if it keeps happening, they can report the code APP_UNHANDLED_REJECTION.

## Ask the user first

None.
