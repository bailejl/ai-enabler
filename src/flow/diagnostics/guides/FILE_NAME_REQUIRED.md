# FILE_NAME_REQUIRED: File name is required

## What it means

The project has no file yet, because it was created in this session and never saved, so `save_project` needs a name for it.

## Repair with the tools

1. Get a file name from the user: a plain name that ends in `.json`, such as `demo.json`.
2. Call `save_project` again with that `name`.

## Ask the user first

What file name to save the new project under. Do not pick one for them.
