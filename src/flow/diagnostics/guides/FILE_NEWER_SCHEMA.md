# FILE_NEWER_SCHEMA: File uses a newer schema

## What it means

The file was saved by a newer version of AI Enabler than this one. This version does not know its fields, so it refuses the file rather than guess.

## Repair with the tools

1. Tell the user the file needs a newer version of AI Enabler, and to update the AI Enabler plugin or app.
2. After the update, call `open_project` again with the same file name.

No tool changes the version of a file.

## Ask the user first

None.
