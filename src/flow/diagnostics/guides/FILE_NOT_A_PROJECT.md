# FILE_NOT_A_PROJECT: File is not a project

## What it means

The file is JSON, but it is not an AI Enabler project: it has no `schemaVersion`, or it is not an object with `nodes` and `edges` lists.

## Repair with the tools

No tool repairs this.

Tell the user this file is not an AI Enabler project file, so it cannot be opened.

Tell the user to choose a file that AI Enabler saved or exported.

Tell the user that once they have the right file, you can call `open_project` again with its name.

## Ask the user first

None.
