# FILE_NOT_JSON: File is not JSON

## What it means

The file's text could not be parsed as JSON, so it is not a readable project. The file is broken or is not a project file at all.

## Repair with the tools

No tool repairs this.

Tell the user this file is not valid JSON, so it cannot be opened.

Tell the user to choose a file saved by AI Enabler, or to repair the JSON syntax in their own copy of the file.

Tell the user that once the file is fixed, you can call `open_project` again with its name.

## Ask the user first

None.
