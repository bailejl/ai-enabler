# FILE_TOO_LARGE: File is too large

## What it means

The project file is larger than 5 MB, so it was not read or saved. A real project file is far smaller, so this file may not be a project or may be damaged.

## Repair with the tools

No tool repairs this.

Tell the user the file is larger than the 5 MB limit and was not read or saved.

Tell the user to use a smaller project file, or to split the work into separate projects.

## Ask the user first

None.
