# FILE_UNREADABLE: File could not be read

## What it means

The chosen file could not be read or checked. It may be locked, moved or deleted, or the system refused to give its contents.

## Repair with the tools

No tool repairs this.

Tell the user the file could not be read, and to choose it again or check that it is not locked or moved.

Tell the user that once the file can be read, you can call `open_project` again with its name.

## Ask the user first

None.
