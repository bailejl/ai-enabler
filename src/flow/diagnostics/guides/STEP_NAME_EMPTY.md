# STEP_NAME_EMPTY: Step name is empty

## What it means

A command was given a step name that is missing, not text, or blank. Nothing was changed.

## Repair with the tools

1. Get a name from the user, with at least one visible character.
2. Call the same tool again with that `name`.

## Ask the user first

What the step should be called, when the user has not said.
