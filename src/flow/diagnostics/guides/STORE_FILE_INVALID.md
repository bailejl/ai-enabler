# STORE_FILE_INVALID: Saved project can't be opened

## What it means

The copy of a project saved in this browser fails validation, so the web app cannot open it. The problems listed after this one say what is wrong with the saved text. This happens in the browser, not in the MCP server.

## Repair with the tools

No tool repairs this.

Tell the user to export the card from the homepage to keep the saved text as a file.

Tell the user to replace the card from a good project file, or delete the card if they no longer need it.

## Ask the user first

None.
