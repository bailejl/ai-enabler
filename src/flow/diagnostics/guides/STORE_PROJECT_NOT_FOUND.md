# STORE_PROJECT_NOT_FOUND: Project not found

## What it means

The link names a project id that is not saved in this browser. The project may have been deleted, saved in another browser, or the link may be mistyped. This happens in the browser, not in the MCP server.

## Repair with the tools

No tool repairs this.

Tell the user to go to the AI Enabler homepage and open the project from its card.

Tell the user that if the project was made in another browser, they can export it there and import the file on this homepage.

## Ask the user first

None.
