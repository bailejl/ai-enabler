# STORE_UNAVAILABLE: Browser storage is not available

## What it means

The AI Enabler web app could not open or read the browser's project storage. Private browsing, a site-data block or a browser policy can cause it. The app keeps working, but projects live only in that browser tab and are gone when it closes. This happens in the browser, not in the MCP server.

## Repair with the tools

No tool repairs this.

Tell the user to export each project they want to keep before closing the tab.

Tell the user to allow site storage for the AI Enabler page in their browser's settings, then reload the page.

## Ask the user first

None.
