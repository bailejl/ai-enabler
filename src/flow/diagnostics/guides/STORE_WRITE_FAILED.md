# STORE_WRITE_FAILED: Change could not be saved in the browser

## What it means

The AI Enabler web app could not write a change to the browser's project storage. A full storage quota or a browser error can cause it. The change stays in the open tab, and the next save that works stores the latest state. This happens in the browser, not in the MCP server.

## Repair with the tools

No tool repairs this.

Tell the user to export the project now so the change is kept in a file.

Tell the user to free some browser storage, for example by deleting projects they no longer need, and then make a change again so the app saves.

## Ask the user first

None.
